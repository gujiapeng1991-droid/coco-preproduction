# 人物圣经 · 标准结构

## 卷首（必备，一页）

三样东西，按顺序：

1. **一句话结构** —— 这部戏到底在讲什么（不是剧情梗概，是人物层面的命题）
   例：一个被当成诱饵养了八年的女孩，要一层层杀穿把她变成诱饵的那套东西。
2. **骨架结构图**（文字版即可）—— 反派阶梯 + 活法答案，见下文「提炼方法」
3. **主题句** —— 从剧本里抠出来的、能概括全剧的一句台词或一个意象
   例：父亲给女儿取字「籽安」——「籽虽微小，落土即生」

卷首写不出来，说明人物还没读透，别急着写正文。

---

## 第一章 · 主要人物小传（10–15 人）

每人一块，**固定九个字段，顺序不许变**：

```markdown
### 姓名 · 称号（阵营）

**① 身份定位** —— 一句话：他在故事里是干什么的岗位。
  例：第二英雄 + 变形者；全剧的「法度视角」。

**② 外貌与标志性符号** —— 只写能变成视觉的：
  一件随身物、一个颜色、一个动作习惯、一处伤疤。
  别写「英俊潇洒」这种没法拍的。

**③ 性格内核** —— 一句话矛盾体。
  例：外层是鹿，内层是刀。／嘴毒、势利、极度自保，但看人极准。

**④ 前史** —— 剧本明确交代过的 + 合理推断，两者要分开写。
  推断的部分标「（推断）」。

**⑤ 本季弧线** —— 逐集写，一集一行，写清「这一集他变了什么」。
  不变的人物要注明「本季无弧线，功能位固定」。

**⑥ 核心戏剧功能** —— 用 Vogler 八原型标注，见下方对照表。
  格式：`原型名 → 服务的哪条主线 → 和谁构成对照镜像`

**⑦ 关系清单** —— 与哪些人、什么关系、这条关系在故事里起了什么作用。
  数量要和关系网 JSON 里的边对得上。

**⑧ 台词风格** —— 句式长短、用词偏好、有没有口头禅。
  给编剧续写和演员找调子用的。

**⑨ 给演员 / 导演的提示** —— 这条人物线最容易演砸的地方是什么。
  例：别演成苦情。她的底色是冷静的算计，不是委屈。
```

## 第二章 · 次要与功能人物速查表（15–20 人）

**表格，一人一行**，四列：

| 姓名 | 身份 | 功能（一句话） | 出场集数 |
|---|---|---|---|

不要展开写小传。谁需要展开，说明他其实该进第一章。

---

## 第三章 · 人物关系总表

按**关系性质**分组，不按人物分组。四类是通用切法：

- **血亲 / 姻亲**
- **情感 / 爱慕**
- **仇杀 / 对抗**
- **控制 / 胁迫 / 利用**
- （有同盟线就加第五组）

每组一张表：`人物 A | 关系 | 人物 B | 这条关系推动了什么`

**这张表的行数 = 关系网 JSON 里 edges 的条数。** 对不上就是有一边漏了。

## 第四章 · 人物核心功能矩阵

一张大表，把所有主要人物按 Vogler 八原型归类：

| 人物 | Vogler 原型 | 服务主线 | 对照镜像 | 结局 |
|---|---|---|---|---|

### Vogler 八原型速查

| 原型 | 戏剧功能 | 判断依据 |
|---|---|---|
| **英雄** | 承担主线、做出核心选择 | 观众跟着他的视点走 |
| **导师** | 给英雄知识/装备/信念 | 英雄在他这里获得能力 |
| **门槛守卫** | 挡路，考验英雄是否ready | 打倒他才能进入下一阶段 |
| **信使** | 带来改变现状的信息 | 他一开口剧情就转向 |
| **变形者** | 立场/身份摇摆，制造不确定 | 观众猜不透他站哪边 |
| **阴影** | 英雄的黑暗面具象化 | 英雄在他身上看到可能的自己 |
| **骗徒** | 打乱节奏、提供喜剧与反转 | 他的存在让局面失控又有趣 |
| **盟友** | 陪伴、执行、捧哏 | 把英雄的心思「说给观众听」 |

补充两个非 Vogler 但常用的：

| 原型 | 功能 |
|---|---|
| **心灵** | 英雄人性未泯的活证据，是「为什么必须活下去」的答案 |
| **圣杯 / 麦高芬** | 所有人行动的目标，本人可能戏份很少 |

## 第五章 · 主线与人物归属

把人物按所属主线重新归一遍组（通常 2–3 条线）：

```markdown
### 主线一 · 复仇线
核心：阿萤 / 阶梯：刀娘 → 疤爷 → 钱大 → 曹公公

### 主线二 · 寻人线
核心：阿萤 → 目标：沈娘

### 主线三 · 法度线
核心：裴决 / 命题：以暴制暴是否被允许
```

要标出**跨线人物**（同时在两条线上起作用的），这些人往往是最关键的。

## 第六章 · 留给下一季的未解扣

剧本里明确没交代的、留了口子的，单列。每条写清：

- 扣是什么
- 剧本里最后一次提到是在哪
- 为什么它必须留着（留着能长出什么）

例：
1. **沈娘生死** —— 紫云苑那场火，名册只有入堂记录、无赎出无身故
2. **陆敬被攥着什么把柄** —— 裴决手里那张牌始终没翻开
3. **「主母令」是谁下的** —— 追杀少年裴决的那道命令，来源成谜

## 提炼方法：怎么找出骨架结构

人物圣经的价值不在小传，在**骨架**。两组必找：

### ① 反派阶梯

把主角面对的所有对手按「代表什么」排个序，检查是否**逐级变大**：

| 层级 | 人物 | 代表什么 |
|---|---|---|
| 一级 | 刀娘 | 私仇，一个人的恶 |
| 二级 | 疤爷 | 共谋，身边人的背叛 |
| 三级 | 钱大 | 规则，一台机器 |
| 四级 | 曹公公 | 制度，一整张网 |

排不出来梯度，说明反派设计扁平，写进文档时要如实指出。

### ② 同一处境的不同答案

找出**起点相似、选择不同**的一组人，看各自下场：

| 人物 | 选择 | 下场 |
|---|---|---|
| 红姑 | 依附 | 死 |
| 柳七 | 只求活 | 死 |
| 疤爷 | 背叛 | 死 |
| 裴决 | 结盟 | 活 |

这组对照就是剧本的**价值观**。找出来，人物圣经才算写完了。
