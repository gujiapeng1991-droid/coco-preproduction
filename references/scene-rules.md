# 分场规则库（顺场表专用）

本文件解决一个核心问题：**一段剧本，怎么切成「场」。**

> 分镜表 skill 负责「一场里怎么切镜头」，本文件负责「剧本怎么切成场」。两者粒度不同，别混。

---

## 一、顺场表 vs 分镜表（别搞混）

| | 顺场表（本 skill） | 分镜表（storyboard-table） |
|---|---|---|
| 粒度 | **一场一行** | 一镜一行 |
| 谁用 | 统筹、制片、导演排期 | 摄影、美术、现场执行 |
| 回答的问题 | 这场在哪拍、谁在、多长、什么氛围 | 这个镜头怎么拍、什么景别、怎么运镜 |
| 编号 | **场号纯数字 `1 / 2 / 3`** | 镜号 `7A / 7B` |
| 核心产出 | **按场次统计**：多少场、多少页、夜戏比、主场景归组 | 镜头数、ASL、单镜时长 |

---

## 二、什么是「一场」

**一场 = 同一时间 + 同一空间 + 同一组人 的连续戏。**

标准剧本格式里，场景标题行（slug line）已经替你分好了：

```
内景·陈默家客厅·夜        ← 这就是一场的开始
```

判断三要素，任一变了就是新的一场：

1. **空间变了**（客厅 → 卧室 → 巷口）
2. **时间跳了**（同一空间，日 → 夜，中间有明显时间流逝）
3. **叙事主体切走**（A 在客厅说话 → 切到 B 在车上，即使同时发生也是两场）

---

## 三、换什么就要另起一场

> **不用 1A / 1B 字母子场。** 一场之内只要出现下面任一情况，**直接开一个新的纯数字场号**。

| 触发条件 | 举例 | 处理 |
|---------|------|------|
| **换了具体位置** | 客厅说话 → 走进卧室继续说 | 拆成 `2`（客厅）与 `3`（卧室） |
| **氛围明显转折** | 前半温馨家常 → 后半翻脸争吵 | 拆成两场，各写各的氛围 |
| **时间档变化** | 黄昏坐到天黑 | 拆成 `黄昏` 一场 + `夜` 一场 |
| **内外跨越** | 从屋内追到门外 | 拆成 `内` 与 `外` 两场 |
| **中间插入别的戏** | 这场拍一半插了别场，回来接着拍 | 后半另起一场 |

### 什么时候**不分场**

- 只是镜头切了（正反打）→ 不分，那是分镜的事
- 人物进出画面 → 不分
- 对白段落多 → 不分，写在同一场的内容梗概里
- 微小机位变化 → 不分

### 编号规则

- **顺序纯数字**：`1`、`2`、`3`、`4`……
- 不许跳号、不许重复、不许字母后缀
- 楔子 / 序幕 / 尾声也并入顺序编号，不写 `楔1` `尾1`
- 场次顺序 = 剧本出现顺序，**不做拍摄顺序重排**（那叫拍摄通告单）

### 容错

老表里如果混进 `1A` `1B` 这类写法，脚本会照原样显示并在运行时打印提示，
统计时按主号去重（1A + 1B = 1 场）。**新项目一律用纯数字。**

## 四、主场景与场景（两列，别写反）

- **主场景** `mainset`：大景，排在场景列**之前**，值由脚本从场景解析，不用手写
- **场景** `set`：`大景-具体位置`

```
主场景：陈默家          场景：陈默家-客厅
主场景：医院            场景：医院-3楼病房
主场景：巷口            场景：巷口（单一位置可省短横线）
```

**为什么分两层**：主场景用于**统筹归组**（同一主场景的戏安排在同一天拍），
具体位置决定走位和置景。只写「医院」太粗，只写「3楼病房」就没法归组。

统计 sheet 的「按主场景归组」、所有占比都按主场景算。

> 写法检查：同一主场景要写成完全一样（`医院-走廊` 与 `医院-3楼病房` 归到「医院」）。
> 全角/半角短横线脚本会归一，但写了别名（`市医院` vs `医院`）就会分成两组——发现分组变多，先查这个。

## 五、氛围词库（mood 列）

氛围写这场戏的**情绪基调**，不是拍法。一个词或两个词，别写句子。

| 大类 | 可选词 |
|------|--------|
| 正向 | 温馨、轻松、欢快、浪漫、治愈、热血、激昂、诙谐、明快 |
| 负向 | 压抑、紧张、阴郁、悲凉、焦灼、沉重、绝望、尴尬 |
| 悬疑类 | 悬疑、惊悚、诡异、不安、窒息、危机四伏 |
| 动作类 | 激烈、紧迫、混乱、硬朗、肃杀 |
| 中性 | 日常、平静、克制、写实、疏离、荒诞、史诗感 |

写法：
- 一场一种基调 → `温馨`
- 基调中途转折 → **另起一场**，各写各的（不要写 `温馨→压抑`）
- 统计区不看氛围列，氛围是给导演和演员看的

## 六、时间档（daynight 列）

| 值 | 含义 | 备注 |
|----|------|------|
| 日 | 白天 | 最省钱的档 |
| 夜 | 夜间 | 需打光，成本上浮 |
| 晨 | 清晨 / 天光初亮 | 抢光窗口窄 |
| 黄昏 | 日落前后 | 抢光窗口最窄，通常单列 |

统计区会算**夜戏占比**——夜戏比例直接决定拍摄周期和预算，是制片最关心的一个数。

---

## 七、内/外（inout 列）

| 值 | 含义 |
|----|------|
| 内 | 室内 |
| 外 | 室外 |

内外跨越的戏**另起一场**分别写内、外，不写 `内外` 这种混合值。
外景受天气影响大，统计区会算**外景占比**，用于评估天气风险。

---

## 八、日/夜 与 内/外 的列位

固定排在**场景之前**，两者紧挨着：

```
… 场号 · 日/夜 · 内/外 · 主场景 · 场景 · 氛围 …
```

理由：先判断「什么时候、室内还是室外」，再看「归到哪个主场景」→「具体在哪儿」，
符合统筹看表的顺序——主场景是归组依据，所以排在场景之前。

> 表内**不设「场次名」列**：剧本的场景标题行原文（`内景·陈默家客厅·夜`）
> 信息已由 日/夜 + 内/外 + 场景 三列拆开覆盖，单列一遍是冗余。

## 九、角色列（每人一列 ✓）

- 顶层 `roles` 声明全部角色，行内 `roles` 数组标该场出场者，**出场格里填单字缩写**（表头写全名）
- 角色名用简称（陈默→`陈`），缩写对照写进 `meta.角色缩写`
- 特约 / 群众走 `extra` / `mass` 列，**不占角色列**
- 完整规范见 `scene-breakdown-schema.md` 第五节
